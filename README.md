# AI Cybersecurity Career Copilot — Basic Version

A beginner-friendly, mobile-responsive career guidance website.

## Run on a phone
1. Download and extract `AI_Cybersecurity_Career_Copilot.zip`.
2. Open `index.html` with a browser (Chrome works).
3. If your phone does not offer an "open with browser" option, use a code editor app that can preview HTML, or upload the extracted folder to a static website host.
4. No Python installation, server, login, or API key is needed for this basic version.

## Features
- Rule-based career assessment
- Seven cybersecurity career profiles
- Four-week learning roadmap with saved progress
- Certification information and official links
- Five-question interview practice quiz
- Local browser storage for roadmap progress

## Project structure
- `index.html` — complete website (HTML, CSS and JavaScript)
- `README.md` — setup and project notes

## Important
This is a basic prototype. Career suggestions are rule-based, not generated by an AI model. Data is saved in the browser's local storage on the device. Do not enter passwords, private information, or sensitive personal data.
